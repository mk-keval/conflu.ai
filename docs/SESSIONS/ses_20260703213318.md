## Actions Taken

1. **Root cause analysis of chart crash ("Something went wrong" on indicator toggle)**
   - `ChartsPage.tsx` used `.map((q) => useQuery(q))` — React hooks violation since `activeIndicators` length changes the number of hook calls
   - `4H chart` had black space because master chart used 400px while others used 300px; `grid-cols-2` row snapped to tallest cell

2. **Fix React hooks violation**
   - Replaced `.map((q) => useQuery(q))` with `useQueries()` for OHLCV queries (stable array length)
   - Replaced multiple `useQuery` calls per indicator with a single combined `useQuery` querying comma-separated indicators
   - Moved `indicatorValues` `useMemo` from inside JSX (conditional behind early return) to top-level

3. **Fix chart height inconsistency**
   - Removed `isMaster` prop from `ChartPane`
   - Uniform `height: 350` for all chart instances
   - Cleaned up unused imports (`useEffect`, `useWS`, `useQueryClient`, WS types)

4. **Clean up dead code**
   - Removed WS indicator event handler (backend uses REST-only for indicators)
